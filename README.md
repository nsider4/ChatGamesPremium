# ChatGames-Premium

Games in your server's chat: unscramble a word, solve a sum, answer a trivia question, be the first to
mine 16 stone. Winners get points, rewards and a place on the leaderboards.

One jar runs on Spigot, Paper and their forks from **1.8.8 to 26.x**, and on **Folia**.

- **[Wiki](https://github.com/nsider4/ChatGamesPremium/wiki)**: installation, commands, games, rewards, troubleshooting.
- **[Developer API](https://github.com/nsider4/ChatGames-API)**: add your own games, races and rewards.
- [Release notes](RELEASE_NOTES.md)

## Building

```
mvn clean package
```

The plugin jar is `target/ChatGames-Premium-<version>.jar`. The `wiki/` folder is the source of the GitHub wiki.
